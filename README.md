# 🐍 Python - Curso em Vídeo

Repositório com a resolução de todos os desafios propostos no curso **Python 3** do canal [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor **Gustavo Guanabara**.

O curso é dividido em **3 mundos**, com mais de 30 horas de aula e **115 desafios práticos**, cobrindo desde o "Olá, Mundo!" até estruturas de dados, funções e tratamento de erros.

📺 Playlist oficial: [Curso de Python 3 - Curso em Vídeo](https://www.youtube.com/playlist?list=PLvE-ZAFRgX8hnECDn1v9HNTI71veL3oW0)

---

## 🌎 O que é ensinado em cada mundo

### Mundo 1 - Fundamentos
Introdução à lógica de programação e à sintaxe do Python: variáveis, tipos de dados, operadores aritméticos, entrada e saída de dados (`input`/`print`), formatação de strings, estruturas condicionais simples (`if/else`) e os primeiros módulos da biblioteca padrão (`math`, `random`).

### Mundo 2 - Estruturas de Controle
Aprofundamento em tomada de decisão com `if/elif/else`, e as estruturas de repetição `for` e `while`. É aqui que surgem os primeiros jogos e desafios de lógica mais elaborados (contadores, validação de entradas, loops aninhados).

### Mundo 3 - Estruturas Compostas
A parte mais robusta do curso: tuplas, listas, dicionários, funções (incluindo `*args`/`**kwargs` e escopo de variáveis), modularização (criação de pacotes e módulos próprios) e tratamento de exceções (`try/except`).

## 🚀 Como executar

Pré-requisitos: [Python 3](https://www.python.org/downloads/) instalado.

```bash
# Clone o repositório
git clone https://github.com/eduduardo-dev/Python-Curso-em-VIdeo.git

# Acesse a pasta desejada
cd Python-Curso-em-VIdeo/mundo-1

# Execute o desafio desejado
python desafio001.py
```
